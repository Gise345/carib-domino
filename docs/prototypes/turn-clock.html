The escalation ladder

Four rungs, each distinct at phone scale — the same test ADR 0014 sets for the board breaking. A player glancing up mid-conversation should know which rung they're on without reading the number.

What each rung is doing

RungFires atVisualWhat the code does
Calm 0–15s Lamplight arc drains clockwise. Board intact. Ring only. No events raised.
Nudge 15s Arc turns amber, first hairline cracks open, banner drops in. TurnTimerEvent.Nudged — raised once. The stalling player's phone buzzes via Haptics.Nudge(), which ignores the vibration setting by design.
Brink last 10s Arc goes danger red, cracks branch and widen to pale raw wood, the whole dial breathes. Presentation only — no new event. Keeps the number readable by pulsing the ring, never the digits.
Break 30s Dial fractures, screen kicks, the chosen tile lifts and slams. TurnTimerEvent.Expired — the authority submits AutoPlaySelector.Pick(...). Never a resign.

Why the digits never pulse. The clock's job in the last ten seconds is to be read, not admired. Motion sits on the ring and the cracks so the numeral stays still and legible — and it keeps UI motion quieter than gameplay motion, which is what DESIGN_SYSTEM.md §4 rations spectacle for.

Palette

Every value here is already in DESIGN_SYSTEM.md §2 — the clock introduces no new colour. The escalation runs along the existing semantic ramp, and the crack interiors reuse the raw-timber tokens the board destruction work is built on.

Where it sits. In the build the clock docks bottom-left, directly above the Last Play tile in the action bar — so the tile just played and the time left on the next one read as one corner, and the middle of the board stays clear. The nudge banner runs to the right of the ring rather than beneath it, where the action bar already lives. Shown here in isolation, at full size.

Design study for the turn timer shipped in feat/turn-timer. Timings mirror TurnTimer.NudgeAfterSeconds (15s) and TurnTimer.ExpireAfterSeconds (30s); the highlighted tile is the move AutoPlaySelector actually returns. Type stands in with rounded system faces — the shipping pair is Baloo 2 and Nunito.
