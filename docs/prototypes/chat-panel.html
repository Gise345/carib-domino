Table chat, rebuilt

Drawn at ship size. The Board canvas is Constant Pixel Size at scale 1, so every number on this page is a Unity unit on a 1080-wide phone — which is exactly why the first pass read as tiny, and why nothing here is smaller than 21px.

The panel

Four people talking mid-hand. It has to be readable at a glance, reportable in one tap, and dismissible without hunting — while the board stays visible enough behind the scrim that you know the game is still there.

The other four states

Every one of these is a real path the panel can land in today. Each says what happened and what to do about it, in that order.

What changes, and why

The build in the screenshot isn't a styling problem — four specific mechanical faults produced it.

FaultCauseFix
Gold columns Icons sat in a HorizontalLayoutGroup with childForceExpandHeight left at its default true, so a 40×40 chat glyph was stretched to the row's full height, and Image.preserveAspect was never set. Every icon goes in a fixed square with preserveAspect = true, and every layout group sets both force-expand flags explicitly.
Everything tiny The Board canvas is Constant Pixel Size, scale 1 — 22px type is 22 device pixels on a 1080-wide phone. Type scale rebuilt at ship size: body 34, names 24, title 46, controls 76–104 tall.
Giant CTA block Same force-expand default: a 230×60 button in a 76-tall row stretched both ways. The locked bar is a row — icon, two lines of copy, one button sized to its label.
“Table dl3010f3-ec3a…” The subtitle printed the raw Photon session id. Ruleset and player count, with the joinable code as a chip. A matchmade table shows no code.

New in this pass: per-seat avatars tying a name to the ring at the table · own messages on the right · timestamps · a "some words were hidden" note under a filtered message · quick phrases for people mid-hand · an unread badge on the HUD button · a bottom-sheet report · and states that say what happened rather than a bare red line.

Deliberately not here: message reactions, typing indicators, and read receipts. Each is a new realtime write path per keystroke, which is a moderation and cost surface for something nobody asks for at a dominoes table.
